JITHIA MARY BYJU - PORTFOLIO SOURCE CODE

How to use:
1. Extract this ZIP.
2. Open the "Jithia-Mary-Byju-Portfolio" folder in VS Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.
4. Keep the videos folder beside index.html so the video players work.

Main files:
- index.html       Main portfolio page
- style.css        Portfolio styling
- Jithia-CV.pdf   Resume
- videos/          Uploaded project videos
